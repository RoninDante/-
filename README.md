# Simple Bash Utils

## Описание

Реализация утилит командной строки Unix `cat` и `grep` на языке C.

- `s21_cat` — чтение и объединение файлов, нумерация строк
- `s21_grep` — поиск текста по шаблону с регулярными выражениями

## Поддерживаемые флаги

### cat

| Флаг | Описание |
|------|----------|
| `-b` | нумерация непустых строк |
| `-e` | отображает `$` в конце строк |
| `-n` | нумерация всех строк |
| `-s` | сжатие пустых строк |
| `-t` | отображает табуляции как `^I` |

### grep

| Флаг | Описание |
|------|----------|
| `-e` | шаблон поиска |
| `-i` | игнорирование регистра |
| `-v` | инверсия |
| `-c` | количество совпадений |
| `-l` | только имена файлов |
| `-n` | номера строк |
| `-h` | без имен файлов |
| `-s` | без ошибок |
| `-f` | шаблоны из файла |
| `-o` | только совпавшая часть |

## Сборка и запуск

```bash
# сборка
make s21_cat
make s21_grep

# запуск cat
./s21_cat -n file.txt

# запуск grep
./s21_grep -i "hello" file.txt

# очистка
make clean
