# Системное программирование на C

## Портфолио проектов

Ниже представлены два проекта, выполненных в рамках изучения системного программирования на языке C. Каждый проект демонстрирует навыки низкоуровневой работы с памятью, файловой системой, обработкой строк и регулярных выражений.

---

## Проект 1: Simple Bash Utils

### Что это

Реализация базовых утилит командной строки Unix — `cat` и `grep` — с полным набором флагов.

### Технологии

- **Язык:** C (C11)
- **Сборка:** Makefile
- **Тестирование:** интеграционные тесты (сравнение с оригинальными утилитами)
- **Регулярные выражения:** библиотека regex.h

### Реализованный функционал

**Утилита cat:**
- Чтение и объединение файлов
- Нумерация всех строк (`-n`) и только непустых (`-b`)
- Отображение непечатаемых символов: концов строк (`-e`), табуляций (`-t`)
- Сжатие нескольких пустых строк (`-s`)

**Утилита grep:**
- Поиск по шаблону с поддержкой регулярных выражений
- Игнорирование регистра (`-i`), инверсия поиска (`-v`)
- Подсчёт количества совпадений (`-c`), вывод номеров строк (`-n`)
- Вывод только имён файлов (`-l`) или только совпавшей части (`-o`)
- Поддержка нескольких шаблонов (`-e`) и чтение шаблонов из файла (`-f`)

## Проект 2: s21_string+

### Что это

Собственная библиотека для работы со строками, реализующая полный аналог `string.h`, а также функции форматированного ввода/вывода.

### Технологии

- **Язык:** C (C11)
- **Сборка:** Makefile (статическая библиотека)
- **Тестирование:** unit-тесты (библиотека Check), сравнение с оригинальной `string.h`
- **Покрытие кода:** gcov (html-отчёт)

### Реализованный функционал

**Часть 1. Функции string.h:**
- Поиск (`memchr`, `strchr`, `strrchr`, `strstr`, `strpbrk`)
- Сравнение (`memcmp`, `strncmp`)
- Копирование и заполнение (`memcpy`, `memset`, `strncpy`)
- Конкатенация (`strncat`), длина (`strlen`, `strcspn`)
- Разбиение на токены (`strtok`), сообщения об ошибках (`strerror`)

**Часть 2-3. Форматированный вывод (sprintf):**
- Спецификаторы: `c`, `d`, `f`, `s`, `u`, `%`, `g`, `G`, `e`, `E`, `x`, `X`, `o`, `p`
- Флаги: `-`, `+`, пробел, `#`, `0`
- Ширина и точность (число, `*`, `.*`)
- Модификаторы длины: `h`, `l`, `L`

**Часть 4. Форматированный ввод (sscanf):**
- Полная поддержка всех спецификаторов и форматов

**Часть 5. Дополнительные функции:**
- Преобразование регистра (`to_upper`, `to_lower`)
- Вставка подстроки (`insert`)
- Обрезка символов (`trim`)
- Конвертация широких строк в UTF-8 (`wcstombs`)

## Навыки, которые демонстрируют эти проекты

- Разработка на C с соблюдением стандарта C11
- Работа с указателями, динамической памятью, файловым вводом-выводом
- Парсинг аргументов командной строки (getopt_long)
- Использование регулярных выражений (regex.h)
- Создание Makefile (сборка, тестирование, очистка)
- Написание unit-тестов и интеграционных тестов
- Форматированный вывод и ввод (собственные реализации sprintf/sscanf)
- Работа с широкими символами и UTF-8
- Соблюдение стиля кода Google Style
- Структурное программирование, модульность, переиспользование кода

## Как запустить

### Simple Bash Utils

```bash
make s21_cat                     # сборка cat
make s21_grep                    # сборка grep

./s21_cat -n file.txt            # запуск cat с флагом -n
./s21_grep -i "hello" file.txt   # запуск grep с флагом -i

make test_cat                    # тесты cat
./test_s21_grep.sh               # интеграционные тесты grep

make clean                       # очистка
```

### s21_string+
```bash
make s21_string.a                # сборка статической библиотеки
make test                        # запуск unit-тестов
make gcov_report                 # генерация отчёта о покрытии кода
make clean                       # очистка
```
