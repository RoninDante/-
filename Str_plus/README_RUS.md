# Проект s21_string+

## Введение

В данном проекте реализована собственная библиотека для обработки строк на языке C, включающая функции стандартной библиотеки string.h, а также дополнительные функции sprintf, sscanf и ряд вспомогательных утилит для работы со строками.

## Инструменты

- **Язык:** C (стандарт C11)
- **Компилятор:** gcc
- **Сборка:** Makefile
- **Тестирование:** библиотека Check
- **Покрытие кода:** gcov (html-отчёт)
- **Стиль кода:** Google Style

## Структура проекта

Проект разделён на 5 частей, каждая из которых реализует определённый набор функций. Все функции имеют префикс `s21_`.

---

## Часть 1. Реализация функций библиотеки string.h

### Цель
Разработать собственную реализацию основных функций библиотеки string.h.

### Реализованные функции

| Функция | Описание |
|---------|----------|
| `s21_memchr` | Поиск первого вхождения символа в первых n байтах строки |
| `s21_memcmp` | Сравнение первых n байтов двух строк |
| `s21_memcpy` | Копирование n символов из одной строки в другую |
| `s21_memset` | Заполнение первых n символов строки заданным символом |
| `s21_strncat` | Добавление строки длиной до n символов в конец другой строки |
| `s21_strchr` | Поиск первого вхождения символа в строке |
| `s21_strncmp` | Сравнение не более первых n байтов двух строк |
| `s21_strncpy` | Копирование до n символов из одной строки в другую |
| `s21_strcspn` | Вычисление длины начального сегмента без указанных символов |
| `s21_strerror` | Возврат строки с сообщением об ошибке по номеру |
| `s21_strlen` | Вычисление длины строки |
| `s21_strpbrk` | Поиск первого символа, совпадающего с любым из заданных |
| `s21_strrchr` | Поиск последнего вхождения символа в строке |
| `s21_strstr` | Поиск первого вхождения подстроки |
| `s21_strtok` | Разбиение строки на токены по разделителям |

### Требования к части 1

- Реализация в виде статической библиотеки `s21_string.a`
- Заголовочный файл `s21_string.h`
- Полное покрытие unit-тестами (библиотека Check)
- Сравнение с оригинальной библиотекой string.h
- Собственный тип `s21_size_t` и макрос `S21_NULL`
- Платформозависимая реализация `s21_strerror` (свои списки ошибок)

## Часть 2. Реализация функции sprintf (частичная)

### Цель
Реализовать функцию `sprintf` с поддержкой базового набора спецификаторов и флагов.

### Поддерживаемый функционал

**Спецификаторы:** `c`, `d`, `f`, `s`, `u`, `%`

**Флаги:** `-` (выравнивание влево), `+` (знак числа), пробел

**Параметры:** ширина (число), точность (`.число`), длина (`h`, `l`)

---

## Часть 3. Дополнительно. Расширенная реализация sprintf

### Цель
Расширить реализацию `sprintf` дополнительными модификаторами формата.

### Дополнительный функционал

**Спецификаторы:** `g`, `G`, `e`, `E`, `x`, `X`, `o`, `p`

**Флаги:** `#` (альтернативная форма), `0` (дополнение нулями)

**Параметры:** ширина (`*`), точность (`.*`), длина (`L` для long double)

---

## Часть 4. Дополнительно. Реализация функции sscanf

### Цель
Реализовать функцию `sscanf` для форматированного ввода из строки.

### Требования
- Полное форматирование с учётом флагов, ширины, модификаторов и типов преобразования
- Поддержка всех спецификаторов, описанных в теоретической части

---

## Часть 5. Дополнительно. Специальные функции обработки строк

### Цель
Реализовать дополнительные утилиты для работы со строками, вдохновлённые классом String из C#.

### Реализованные функции

| Функция | Описание |
|---------|----------|
| `s21_to_upper` | Преобразование строки в верхний регистр |
| `s21_to_lower` | Преобразование строки в нижний регистр |
| `s21_insert` | Вставка подстроки в указанную позицию |
| `s21_trim` | Удаление заданных символов из начала и конца строки |

### Особенности
- При ошибках возвращают `NULL`
- Работают с однобайтовыми символами в кодировке ASCII
