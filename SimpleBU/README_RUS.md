# Simple Bash Utils

## Введение

В рамках проекта реализованы базовые утилиты Bash для работы с текстом: cat и grep.

## Инструменты

- **Язык программирования:** C (стандарт C11)
- **Компилятор:** gcc
- **Сборка:** Makefile
- **Библиотеки для регулярных выражений:** PCRE, regex
- **Тестирование:** интеграционные тесты с сравнением поведения с реальными утилитами Bash
- **Стиль кода:** Google Style
- **Принципы:** структурное программирование, исключение дублирования кода

## Описание утилит

### Утилита cat

cat — одна из наиболее часто используемых команд в Unix-подобных операционных системах. Команда имеет три взаимосвязанные функции в отношении текстовых файлов: отображение, объединение их копий и создание новых.

**Формат:** `cat [OPTION] [FILE]...`

**Поддерживаемые опции:**

| № | Опция | Описание |
| ------ | ------ | ------ |
| 1 | -b (GNU: --number-nonblank) | нумерует только непустые строки |
| 2 | -e (GNU: -E) | отображает символы конца строки как $ |
| 3 | -n (GNU: --number) | нумерует все выходные строки |
| 4 | -s (GNU: --squeeze-blank) | сжимает несколько смежных пустых строк |
| 5 | -t (GNU: -T) | отображает табы как ^I |

### Утилита grep

grep — утилита для поиска строк, соответствующих заданному шаблону с использованием регулярных выражений.

**Формат:** `grep [options] template [file_name]`

**Поддерживаемые опции:**

| № | Опция | Описание |
| ------ | ------ | ------ |
| 1 | -e | шаблон |
| 2 | -i | игнорирует различия регистра |
| 3 | -v | инвертирует смысл поиска соответствий |
| 4 | -c | выводит только количество совпадающих строк |
| 5 | -l | выводит только совпадающие файлы |
| 6 | -n | предваряет каждую строку вывода номером строки |
| 7 | -h | выводит совпадающие строки без имен файлов |
| 8 | -s | подавляет сообщения об ошибках |
| 9 | -f file | получает регулярные выражения из файла |
| 10 | -o | печатает только совпадающие части строки |

## Реализация

### Требования к разработке

- Код утилит cat и grep расположен в директориях `src/cat/` и `src/grep/` соответственно.
- Сборка настроена с помощью Makefile с целями `s21_cat` и `s21_grep`.
- Исполняемые файлы называются `s21_cat` и `s21_grep`.
- Общие модули вынесены в директорию `src/common`.
- Код покрыт интеграционными тестами для всех вариантов флагов и входных значений.

### Часть 1. Утилита cat

Реализована утилита cat с поддержкой всех указанных флагов (включая GNU версии).

### Часть 2. Утилита grep

Реализована утилита grep с поддержкой флагов: `-e`, `-i`, `-v`, `-c`, `-l`, `-n`.

### Часть 3. Дополнительно. Реализация дополнительных флагов grep

Реализована поддержка флагов: `-h`, `-s`, `-f`, `-o`.

### Часть 4. Дополнительно. Реализация комбинаций флагов grep

Реализована поддержка парных комбинаций флагов (например, `-iv`, `-in`).
